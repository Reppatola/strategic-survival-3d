# Changelog

Все значимые изменения проекта. Формат версии: `NNNNv.ДД.ММ.ГГГГ`.

## [0016v.28.09.2026] — Fix: крикун зовёт зомби

### Исправлено
- **Импульс `scream` не добавлялся в `NoiseSystem`.** После рефакторинга
  в 0012 крик добавлял только визуальный флаг `didScream`, но не world-импульс.
  Зомби не слышали крик и не шли на зов.
- **Крикун молчал в CHASE.** Крик срабатывал только при входе в ALERT.
  Если крикун уже в погоне, cooldown истекал, а крика не было.

### Изменено
- **`Zombie.js`** — метод `_tryScream(noiseSystem)`, вызывается из `_enterAlert`
  и из `CHASE` (пока видит/слышит игрока).
- **`zombie.config.js`** — `scream.cooldown` 8 → 4 сек.

## [0015v.28.09.2026] — Fix: зомби не теряет игрока вплотную

### Исправлено
- **Потеря цели в CHASE.** Если зомби подошёл вплотную, но смотрел мимо
  (после атаки rotation.y не обновлялся), через `chaseLossTimeout = 1.5`
  он уходил в SEARCH и прекращал бить.
- **Поворот в CHASE.** Зомби теперь поворачивается к игроку, если тот
  вплотную, но вне конуса зрения.

### Изменено
- **`Zombie.js`** — переменная `nearPlayer` (dist < attackRange × 1.5),
  используется в `CHASE` и `SEARCH`.

## [0014v.28.09.2026] — Модель игрока: силуэт и анимация

### Добавлено
- **Многочастная модель игрока**: торс, голова, визор, две руки, пистолет, две ноги.
- **Анимация ходьбы**: пивоты в плечах и бёдрах, махи ног и левой руки.
- **Покачивание тела** при ходьбе через `bodyGroup.position.y`.
- **Амплитуда и частота махов** зависят от режима: crouch / walk / sprint.
- **Плавный возврат в покой** при остановке.

### Изменено
- **`Player.js`** — переписан `_buildModel()`, добавлены `_animateWalk()` и `_animateIdle()`.
- **`bodyGroup`** — новый контейнер для визуала, отделён от world position.

## [0012v.28.09.2026] — ALERT-слой: окно реакции

### Добавлено
- **Состояние `ALERT`** в state machine зомби — замирание и поворот к сигналу.
- **Формула длительности ALERT**: `base × (1 − confidence_bonus) × silence_penalty`.
  Уверенность сенсора (слух/зрение) сокращает телеграф до −50%.
- **`alert` и `search` блоки в конфиге** по типам: base, silencePenalty, persistence, radius.
- **`_visionConfidence`** — аналог `_hearingConfidence`, растёт при визуальном контакте.
- **Визуальный телеграф** — пульсирующее кольцо вокруг зомби в ALERT.
- **Окраска конуса зрения по состоянию** в `SensorVisualizer`: жёлтый → ярко-жёлтый → красный.
- **Screamer кричит в начале ALERT** — окно среагировать равно длительности крика.
- **`ZOMBIE.confidenceAlertBonus`** (0.5), **`chaseLossTimeout`** (1.5 сек), **`chaseJumpConfidence`** (0.7).

### Изменено
- **`Zombie.js`** — полный rewrite с переходом на switch-case машину состояний.
- **`zombie.config.js`** — новые блоки `alert` и `search` для каждого типа.
- **`SensorVisualizer.js`** — принимает `dt`, пульсирует конус в ALERT.
- **`Game.js`** — передаёт `dt` в `SensorVisualizer.update`.

### Технически
- **SEARCH длительность**: walker 5, sniffer 3, listener 10, screamer 10 сек.
- **ALERT длительность**: walker 0.8, sniffer 1.1, listener 0.5, screamer 1.4 сек.

## [0008v.28.09.2026] — Позиционный звук

### Добавлено
- **Позиционное аудио**: громкость и панорама зависят от точки источника.
- **`AudioSystem.playAt(name, sx, sz, lx, lz)`** — универсальный вызов.
- **Синтез крика крикуна**: пилообразный тон с вибрато + шумовая подложка, длительность 1.4 сек.
- **Затухание с расстоянием**: `volume = 1 / (1 + d·0.05)`.

### Изменено
- **`AudioSystem.js`** — переход на цепочку `gain → StereoPanner → master`.
- **`Game.js`** — вызовы звука через `playAt()` с координатами.
- **`audio.config.js`** — параметры затухания и крика.

## [0006v.27.09.2026] — Звук: выстрел и шаги

### Добавлено
- **`AudioSystem`** — синтезированные звуки через Web Audio API (без файлов).
- **Звук выстрела**: белый шум с полосовым фильтром + низкочастотный thump.
- **Звуки шагов**: три режима (crouch/walk/sprint) с разной громкостью и фильтром.
- **`audio.config.js`** — настройки громкостей и длительностей.
- **Разблокировка звука** при первом взаимодействии с пользователем.

### Изменено
- **`Game.js`** — интеграция `AudioSystem`, вызовы `playShot()` и `playStep()`.

## [0005v.27.09.2026] — AI восприятия: слух, зрение, нюх

### Добавлено
- **Система восприятия зомби**: три сенсора — слух, зрение, нюх — с приоритетом.
- **State machine**: `IDLE → SEARCH → CHASE → ATTACK`.
- **Накопление уверенности для слуха**: одиночный выстрел не поднимает зомби, очередь — поднимает.
- **Конус обзора** с проверкой перекрытия зданий (LOS).
- **Четыре типа зомби**:
  - 🟢 **Walker** — обычный, средний слух, среднее зрение.
  - 🟤 **Sniffer** — нюхач, идёт по запаху с ошибкой.
  - 🔵 **Listener** — слухач, срывается на 40 м от тихой ходьбы.
  - 🔴 **Screamer** — крикун, поднимает всех зомби при виде игрока.
- **Смешанный спавн**: 6 walker + 1 каждого спеца.
- **Крик крикуна** как глобальный шум 120 dB через `NoiseSystem`.

### Изменено
- **`Zombie.js`** — полностью переписан под восприятие и state machine.
- **`SpawnSystem.js`** — метод `spawnMixed` вместо `spawnRing`.
- **`Game.js`** — интеграция смешанного спавна.

## [0004v.27.09.2026] — Физическая модель шума

### Добавлено
- **Энергетическая сумма источников**: `LΣ = 10·log10(Σ 10^(Lᵢ/10))`.
- **Линейное затухание импульсов**: `L(t) = L₀ − k·t` с индивидуальным `k`.
- **Затухание с расстоянием**: `L(d) = L₀ − 20·log10(d/d₀)`.
- **Палитра источников**: удар, дверь, топор, ящик, молоток, стекло, пистолет, дробовик, винтовка, взрыв.
- **Одноразовые действия Q/E/F**: удар (20 dB), стекло (60 dB), взрыв (145 dB).
- **Кольцо шума** под игроком (`NoiseRing`), зависящее от dB.
- **Вспышка выстрела** (`MuzzleFlash`) у дула.
- **Разбор шума по источникам в HUD**.

### Изменено
- **`NoiseSystem.js`** — переход с «база + импульс» на физическую модель.
- **`Zombie.js`** — слышимость теперь зависит от расстояния до зомби.
- **`HUD.js`** — показывает разбор: база + активные импульсы.

### Удалено
- **`AlertSystem.js`** — роль перешла к `NoiseSystem` (поля `critical`, `criticalTime`).

## Как добавить новую версию

1. Скопируй блок заголовка `## [NNNNv.ДД.ММ.ГГГГ] — Название`.
2. Номер сборки — следующий по порядку (`0006`, `0007`, ...).
3. Дата — текущая в формате `ДД.ММ.ГГГГ`.
4. Название — короткое, 2–4 слова, суть изменения.
5. Заполни секции: **Добавлено**, **Изменено**, **Исправлено**, **Удалено**.
6. Свежие версии — **сверху**, не снизу.

## Правила

- **Одна версия = одно значимое изменение.** Не смешивай «добавил зомби» и «поправил опечатку в README» в один релиз.
- **Не пиши «мелкие фиксы»** — либо описывай конкретно, либо пропускай.
- **Ссылайся на файлы**, если менял архитектуру: «`NoiseSystem.js` — переход на модель X».
- **Дата в формате ДД.ММ.ГГГГ.** Даже если кажется неудобным — этот формат однозначен для читателя.
