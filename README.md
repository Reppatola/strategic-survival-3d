# Strategic Survival 3D

**Версия: 0010v.28.09.2026** · [Changelog](./CHANGELOG.md)

Twin-stick survival в one-point perspective. Ты видишь мир сверху, но камера слегка «заглядывает» туда, куда смотрит прицел — так ты видишь угрозу раньше, чем она увидит тебя.

## Играть

[Открыть игру](https://reppatola.github.io/strategic-survival-3d/)

Работает прямо в браузере, установка не нужна. Требуется мышь и клавиатура.

## Что реализовано

### Ядро
- Twin-stick управление: движение отдельно, прицел отдельно.
- One-point perspective камера: строго сверху, со смещением в сторону прицела.
- Мёртвая зона прицела: мелкие движения мыши не дёргают камеру.
- Фиксированный dt: игровой цикл стабилен после сворачивания вкладки.

### Мир
- Генерация города: дома через InstancedMesh.
- Двускатные крыши на домах.
- Деревья: ствол + низкополигональная крона.
- Коллизии: скольжение вдоль стен, проверка перекрытия линии видимости.
- Ранний отсев в lineBlocked по bounding box отрезка.

### Физическая модель шума

Реализована честная акустика, а не «громко/тихо»:

- Энергетическая сумма: LSum = 10·log10( SUM 10^(Li/10) ).
  Два выстрела (110 + 110) дают 113 dB, а не 220.
- Линейное затухание импульса: L(t) = L0 - k·t, где k индивидуален для каждого источника.
- Затухание с расстоянием: L(d) = L0 - 20·log10(d/d0), d0 = 1 м.
  Выстрел 110 dB слышен на 1 км, ходьба 50 dB — только на 40 м.

Палитра источников (L0 dB / k dB/сек):

| Источник | L0 | k |
|---|---|---|
| Удар рукой | 20 | 80 |
| Дверь | 15 | 80 |
| Топор | 35 | 70 |
| Ящик | 40 | 65 |
| Молоток | 45 | 65 |
| Стекло | 60 | 70 |
| Пистолет | 110 | 70 |
| Дробовик | 125 | 55 |
| Винтовка | 130 | 60 |
| Взрыв | 145 | 45 |
| Крик крикуна | 120 | 20 |

Разделение слоёв шума:
- Свой шум игрока (ownTotal) — база + собственные импульсы. Идёт в HUD и критический режим.
- Мировой шум — импульсы от чужих источников (крик крикуна). Не влияет на HUD, но слышен зомби через levelAtPoint.

Позиционность: каждый импульс помнит свои координаты. Крик крикуна звучит от него, а не от игрока.

Критический режим с гистерезисом 120/60 dB — только от собственного шума игрока.

### AI восприятия зомби

Три сенсора с приоритетом: зрение > слух > нюх.

- Слух: накопление уверенности. Одиночный выстрел не поднимает, очередь — поднимает.
- Зрение: конус + проверка перекрытия стен (LOS).
- Нюх: направленный, постоянный, с ошибкой.

State machine: IDLE → SEARCH → CHASE → ATTACK.

Четыре типа зомби:

| Тип | Цвет | Слух | Зрение | Нюх | Особое |
|---|---|---|---|---|---|
| Walker | green | x1.0 | 30 м / 60° | — | — |
| Sniffer | brown | x0.6 | 12 м / 50° | 45 м / 90° | Идёт по запаху с ошибкой |
| Listener | blue | x2.5 | 15 м / 60° | — | Слышит тихую ходьбу |
| Screamer | red | x1.2 | 25 м / 70° | — | Кричит при виде, поднимает всех |

Whiskers: если прямой шаг к цели заблокирован — пробуем повернуть на ±60° и ±120°.

### Игрок
- HP и смерть: полоска здоровья в HUD, экран «ВЫ ПОГИБЛИ».
- Урон с неуязвимостью: 0.4 сек после удара.
- Красная вспышка по краям экрана при получении урона.
- Поворот к прицелу.

### Визуал
- Кольцо шума под игроком, зависит от ownTotal.
- Вспышка выстрела у дула.
- Следы шагов, гаснут через 1.5 сек.
- Прицел: кольцо + луч от игрока.

### Звук

Синтезированные звуки через Web Audio API — не нужны mp3, всё работает сразу.

- Выстрел: белый шум с полосовым фильтром + низкочастотный thump.
- Шаги: три режима (crouch / walk / sprint) с разной громкостью и фильтром.
- Крик крикуна: пилообразный тон с вибрато + шумовая подложка, длительность 1.4 сек.

Позиционное аудио: громкость и панорама зависят от точки источника.
volume = 1 / (1 + d·0.05) — это перцептивный falloff для игрока за монитором, не путать с физическим falloff в NoiseSystem.

Разблокировка звука: браузеры требуют первого клика/нажатия клавиши.

### Визуализация сенсоров (debug)

Нажми V — увидишь:

- Жёлтые конусы — зрение каждого зомби. Вращаются вместе с ним.
- Оранжевое кольцо вокруг игрока — радиус слышимости текущего шума.
- Фиолетовое кольцо вокруг нюхачей — радиус нюха 45 м.

Кольцо слуха растёт/сжимается в реальном времени.

## Стек

- Three.js — 3D-рендер.
- Vite — сборка и dev-сервер.
- Vanilla JS — чистые ES-модули, без фреймворков.
- Web Audio API — синтез звуков.
- GitHub Actions — автодеплой на GitHub Pages.

## Структура проекта

src/config/ — все тюнинг-константы (game, camera, player, noise, zombie, audio).
src/core/ — движок (Game, Loop, Renderer).
src/world/ — генерация домов и деревьев.
src/entities/ — Player, Zombie, BulletPool, FootprintPool, NoiseRing, MuzzleFlash.
src/systems/ — Input, Aim, CameraRig, Collision, Noise, Spawn, Audio.
src/ui/ — HUD, Crosshair, DamageIndicator.
src/debug/ — SensorVisualizer (клавиша V).
src/i18n/ — локализация (en, ru, fr, de, es).

## Принципы архитектуры

1. Один файл — одна ответственность. Zombie.js знает только про зомби.
2. Логика отделена от данных. Все константы — в src/config/.
3. Сущности не знают друг о друге. Game.js связывает их.
4. Уровни — это данные. Локации лежат в levels/*.json.
5. Никаких циклических импортов.

Проект автоматически публикуется на GitHub Pages при каждом пуше в main.

## Известные ограничения

- Тени работают в радиусе ±70 от игрока.
- Зомби ходят сквозь деревья — у стволов пока нет коллизий.
- Зомби застревают в сложных углах — whiskers помогают на 90% случаев.
- Звук синтезирован, не сэмплы.
- Сектор нюха отображается кольцом, а не конусом.
