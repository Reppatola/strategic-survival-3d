# Strategic Survival 3D

Twin-stick survival в one-point perspective. Ты видишь мир сверху, но камера слегка «заглядывает» туда, куда смотрит прицел — так ты видишь угрозу раньше, чем она увидит тебя.

## 🎮 Играть

**▶️ [Открыть игру](https://reppatola.github.io/strategic-survival-3d/)**

Работает прямо в браузере, установка не нужна. Требуется мышь и клавиатура.

## ⌨️ Управление

| Действие | Клавиша |
|---|---|
| Движение (8 направлений) | `W` `A` `S` `D` |
| Прицел | Мышь |
| Выстрел | ЛКМ |
| Бег (громко) | `Shift` |
| Красться (тихо) | `C` |

## ✨ Что уже реализовано

### Ядро
- **Twin-stick управление**: движение отдельно, прицел отдельно.
- **One-point perspective камера**: строго сверху, но со смещением в сторону прицела.
- **Мёртвая зона прицела**: мелкие движения мыши вокруг героя не дёргают камеру.
- **Разная скорость наведения/возврата камеры**: к угрозе — резко, обратно — плавно.
- **Фиксированный dt**: игровой цикл стабилен, не «прыгает» после сворачивания вкладки.

### Мир
- **Генерация города**: дома разной высоты и цвета через `InstancedMesh` (десятки зданий — один вызов рендера).
- **Деревья**: ствол + низкополигональная крона, тоже инстансами.
- **Коллизии**: игрок скользит вдоль стен и не проходит сквозь дома.
- **Тени и туман**: направленный свет с картой теней, дальний туман скрывает границы мира.

### Игрок
- **HP и смерть**: полоска здоровья в HUD, экран «ВЫ ПОГИБЛИ».
- **Урон с неуязвимостью**: 0.4 секунды неуязвимости после удара.
- **Красная вспышка по краям экрана** при получении урона.
- **Поворот к прицелу**: герой смотрит туда, куда наведена мышь.

### Система Шума
- **База от движения**: `CROUCH` 30 dB, `WALK` 50 dB, `SPRINT` 70 dB.
- **Импульсы**: выстрел добавляет +60 dB, затухает за ~1.5 секунды.
- **Плавная интерполяция**: базовый шум не прыгает, а «дышит».

### Тревога
- **Включение** при dB ≥ 100.
- **Минимальная длительность 12 секунд**, даже если сразу замолчал.
- **Отключение** при dB ≤ 10 после истечения таймера.
- **Пульсирующая плашка** сверху по центру.

### Враги
- **Зомби идут на шум, а не на игрока**: точность зависит от громкости.
- **Точность слышимости**: 45 dB — ошибка ~10 м, 110 dB — ошибка ~2 м.
- **Атака вблизи**: 10 урона раз в секунду.
- **Смерть от пуль**: радиус попадания 0.6 м.
- **Пул пуль**: 24 переиспользуемых объекта, без аллокаций в рантайме.

### Локализация
- **Автодетект языка браузера** при загрузке.
- **Поддержка**: английский (фолбэк), русский, французский, немецкий, испанский.
- **Добавить новый язык** — один файл в `src/i18n/locales/`.

## 🛠️ Стек

- **Three.js** — 3D-рендер.
- **Vite** — сборка и dev-сервер.
- **Vanilla JS** — без фреймворков, чистые ES-модули.

## 🏛️ Принципы архитектуры

1. **Один файл — одна ответственность.** `Zombie.js` знает только про зомби. `CameraRig.js` — только про камеру.
2. **Логика отделена от данных.** Все константы — в `src/config/`. Меняешь цифры, не трогая код.
3. **Сущности не знают друг о друге.** `Game.js` связывает их. `Player` не знает про `Zombie`, `Zombie` не знает про `CameraRig`.
4. **Уровни — это данные.** Локации лежат в `levels/*.json` и просто «проигрываются» движком.
5. **Никаких циклических импортов.** Каждый модуль зависит только от более низких уровней.

## 💻 Запуск локально

```bash
git clone https://github.com/Reppatola/strategic-survival-3d.git
cd strategic-survival-3d
npm install
npm run dev
```

Открой [http://localhost:5173](http://localhost:5173) в браузере.

### Запуск через Codespaces

1. Открой репозиторий на GitHub.
2. **Code → Codespaces → Create codespace on main**.
3. В терминале: `npm run dev`.
4. Открой появившуюся ссылку (порт 5173 будет проброшен автоматически).

## 🚀 Деплой

Проект автоматически публикуется на GitHub Pages при каждом пуше в `main`. Ничего вручную делать не нужно — просто коммить и пушить.

**Workflow:** `.github/workflows/deploy.yml`.

**Ключевой момент:** `vite.config.js` в корне содержит `base: '/strategic-survival-3d/'`. Без него ассеты будут искаться в корне домена и получат 404.

**Ссылка на игру:** [https://reppatola.github.io/strategic-survival-3d/](https://reppatola.github.io/strategic-survival-3d/)

## 🌍 Добавить новый язык

1. Создай `src/i18n/locales/xx.js` (где `xx` — код языка).
2. Скопируй структуру из `en.js` и переведи значения.
3. Добавь импорт и запись в объект `LOCALES` в `src/i18n/index.js`:

```js
import xx from './locales/xx.js';
const LOCALES = { en, ru, fr, de, es, xx };
```

4. Всё — язык автоматически подхватится, если у игрока он в браузере.

## 🐛 Известные ограничения

- **Тени работают в радиусе ±70** от игрока. Дальше shadow map не достаёт — картинка тускнеет. Исправим, когда перейдём к большим мирам.
- **Зомби ходят сквозь деревья.** У стволов пока нет коллизий.
- **Зомби застревают в углах домов.** Простое AABB-скольжение не умеет обходить препятствия. Решим через pathfinding.
- **Нет звука.** Все эффекты визуальные.
