# Концепты окружения

Земля, дороги, детали, из которых собирается локация.

## Что нужно

- **Трава** — текстура или цвет для земли.
- **Дороги** — асфальт, грунтовка, тропы.
- **Пятна** — вытоптанная земля, лужи, грязь.
- **Разметка** — для ориентира игрока.
- **Границы** — заборы, ограждения (не только физические, но и визуальные).
