# Концепты объектов

Мелкие объекты окружения: деревья, кусты, ящики, бочки, фонари, заборы.

## Что нужно

- **Деревья** — 2-3 разных типа (высокое, кустистое, мёртвое).
- **Кусты** — для укрытия и атмосферы.
- **Ящики, бочки** — можно спрятаться, можно разбить.
- **Фонари** — источники света (будут работать ночью).
- **Заборы** — границы территорий.
- **Камни** — заполнители пространства.

## Требования

- Low-poly, до 200 трис на объект.
- Стилизация под общий визуал — flat shading, чёткие грани.
- Используются через `InstancedMesh` — рисуются сотнями за один вызов.
