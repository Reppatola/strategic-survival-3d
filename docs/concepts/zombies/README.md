# Концепты зомби

Рисунки всех типов зомби. Каждый тип должен читаться **с первого взгляда** —
силуэт, поза, характерная деталь.

## Типы и характеристики

| Тип | Цвет | Слух | Зрение | Нюх | Особое |
|---|---|---|---|---|---|
| Walker | 🟢 зелёный | ×1.0 | 30 м / 60° | — | Обычный, средний |
| Sniffer | 🟤 коричневый | ×0.6 | 12 м / 50° | 45 м / 90° | Принюхивается, ведёт по запаху |
| Listener | 🔵 синий | ×2.5 | 15 м / 60° | — | Настороженный, прислушивается |
| Screamer | 🔴 красный | ×1.2 | 25 м / 70° | — | Открытый рот, кричит, зовёт орду |

## Что важно в концепте

- **Walker** — сгорбленный, руки вытянуты, потрёпанная одежда.
- **Sniffer** — приземистый, голова наклонена к земле, большие ноздри,
  руки-щупальца для поиска следа.
- **Listener** — вытянутый, голова набок, большие уши или
  характерные наросты (слышит на 40 м тихий шум).
- **Screamer** — раздутое горло, открытый рот, тонкие руки.
  Игрок должен за 1.4 сек ALERT понять — «сейчас заорёт».
