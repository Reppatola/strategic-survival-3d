# Концепты 3D-моделей

Папка для рисунков, эскизов и референсов будущих 3D-моделей.
Когда модели попадут в Blender — здесь остаются концепты как история.

## Категории

- [zombies/](./zombies/) — все типы зомби: walker, sniffer, listener, screamer
- [player/](./player/) — игрок, экипировка, оружие
- [buildings/](./buildings/) — дома, крыши, стены, двери
- [props/](./props/) — деревья, ящики, бочки, фонари
- [environment/](./environment/) — земля, дороги, детали окружения

## Формат

- **PNG / JPG** — рисунки, сканы, скриншоты.
- **Названия** — `walker_front.png`, `walker_side.png`, `house_2story.png`.
- Один файл = один ракурс. Не склеивай разные виды в одну картинку.

## Статусы моделей

В `README.md` каждой папки ведётся таблица: концепт → модель → игра.

| Статус | Значение |
|---|---|
| 📝 Концепт | Рисунок есть |
| 🎨 Модель | Есть .blend или .glb |
| 🎮 В игре | Интегрирована |
