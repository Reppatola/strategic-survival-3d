# Концепты зданий

Дома, крыши, стены, двери, окна. Всё, что образует город.

## Что нужно

- **Дом 1 этаж** — стандарт, встречается часто.
- **Дом 2-3 этажа** — редкий, узнаваемый силуэт.
- **Разрушенный дом** — без крыши, обломки.
- **Сарай / ангар** — длинный, низкий.
- **Крыши** — двускатные, плоские, шифер, черепица.

## Требования

- **Меньше 500 трис на дом.** Силуэт — коробка + крыша.
- Детали (окна, двери) — плоские текстуры или накладные плоскости,
  а не настоящая геометрия.
- Крыша всегда должна быть видна сверху — игрок смотрит под углом.
