# Концепты игрока

Рисунки главного героя, экипировки и оружия.

## Что в этой папке

- Силуэт героя (спереди / сбоку / сзади).
- Одежда, броня, детали костюма.
- Оружие: пистолет, дробовик, винтовка, взрывчатка.
- Анимационные позы: стойка, ходьба, бег, красться, прицеливание.

## Требования

- Стиль: **low-poly friendly**. Не перегружай деталями,
  каждая часть должна читаться с высоты полёта камеры (34 м).
- Силуэт важнее деталей. Игрок видит тебя с высоты — мелкие пряжки
  и логотипы не различить.
- Цвет — жёлто-оранжевая палитра, чтобы не сливаться с зелёной травой
  и не путаться с зелёными зомби.
